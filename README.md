# Svajonų Burbulai

Tai lengvai pritaikoma vaikų švenčių organizavimo svetainė su skirtingais skyrius: personažai, programos, galerija, kainos, atsiliepimai ir kontaktai.

## Kaip naudotis

1. Atidarykite `index.html` naršyklėje arba paleiskite lokaliai:
   ```bash
   python -m http.server 8000
   ```
2. Svetainėje atidarykite administravimo nuorodą apačioje arba eikite į `admin.html`.
3. Įveskite slaptažodį: `svajonuburbulai2025`
4. Redaguokite tekstus, nuotraukas, personažus, kainas ar kontaktus tiesiai skydelyje.

## Svarbu

- Ši versija yra statinis puslapis, todėl administravimas veikia naršyklėje ir išsaugo duomenis vietiniame lauke.
- Jei norėsite, vėliau galime paprasčiausiai prijungti pilną serverinę administraciją su duombaze ir nuolatiniais duomenimis.
